# DarasaX

**Everything for class. One place.**

A modern student academic companion for modules, notes, assignments, past papers, timetables, announcements, study planning, and AI-powered learning tools.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- next-themes (light / dark / system)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Demo flow

1. Landing → **Get Started**
2. Sign up → Onboarding (institution → programme → year → semester → class)
3. Dashboard and student tools (mock data, no backend yet)

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
